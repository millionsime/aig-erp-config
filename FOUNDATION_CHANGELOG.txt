E. COST CENTER ON BALANCE-SHEET ACCOUNTS  (brief Section 5.1 - the big one)
================================================================================
v16 ENGINE REALITY (verified in source, scripts/42-45):
1. The "Allow Cost Center In Entries of Balance Sheet Account" setting DOES
   NOT EXIST in v16 (grep across all of erpnext: zero hits). CC tagging of
   BS accounts is always permitted in v16. Nothing to enable; the brief's
   step was written for v13-era behaviour.
2. GL-level CC enforcement: P&L accounts already REQUIRE a CC natively
   (gl_entry.pl_must_have_cost_center). BS accounts did not - that is what
   this build adds, at the transaction layer.
3. The Accounting Dimension "Mandatory For" mechanism CANNOT be used for
   Cost Center: accounting_dimension.py validate_doctype() explicitly throws
   "Not allowed to create accounting dimension for Cost Center" (CC is a
   built-in dimension). So mandatory-CC is implemented as config-layer
   enforcement instead - see below.

PROPERTY SETTERS (reqd=1) - 6 records:
  Payment Entry.cost_center, Sales Invoice.cost_center,
  Sales Invoice Item.cost_center, Purchase Invoice.cost_center,
  Purchase Invoice Item.cost_center, Journal Entry Account.cost_center
  (Payment Entry's native CC field was checked for hidden=0 - it is visible.)
  Purchase Order/Sales Order CC comes from the demo layer's mandatory custom
  field (aig_cost_center) + the existing defaulting Server Script.

SERVER SCRIPTS (RestrictedPython sandbox; DocType Event = Before Validate) - 4:
  "AIG - CC Guard Journal Entry"   defaults row CC from header then Company
                                   default; throws if any row would post
                                   without a CC.
  "AIG - CC Guard Payment Entry"   defaults header CC from Company default;
                                   throws if still empty (PE CC flows to all
                                   its GL rows - verified in source).
  "AIG - CC Guard Sales Invoice"   header/items/taxes default + enforce.
  "AIG - CC Guard Purchase Invoice" same for purchase side.
  All four use frappe.db.get_value("Company", doc.company, "cost_center") -
  the correct v16 fieldname (see note in section B).

BACKFILL: draft Payment Entry ACC-PAY-2026-00003 (demo live-flow doc) had no
  CC -> set to Head Office - AIG so it passes the new mandatory rule.

NO new custom "Enterprise" dimension was created (brief 5.2). Cost Center IS
the enterprise dimension. Branch-level tracking noted as a future option.
